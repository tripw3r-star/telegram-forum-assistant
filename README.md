# 🤖 Telegram Forum AI Assistant Bot

> **Интеллектуальный ИИ-ассистент для супергрупп с темами (ветками / форумом) в Telegram.**  
> Разработан для автоматической каталогизации базы знаний команды, анализа полезных ссылок, репозиториев, видео и файлов, а также генерации задач и дайджестов.

---

## 🌟 Основные возможности

### 1. 📥 Умный разбор ветки «Входящие»
* Участники группы кидают во «Входящие» любые материалы:
  * 🌐 **Веб-ссылки и статьи:** бот выходит в интернет, парсит контент и выжимает суть.
  * 🐙 **GitHub-репозитории:** через GitHub API извлекаются звёзды, основной стек, лицензия, активность и фрагмент документации `README.md`.
  * 🎬 **YouTube-видео:** извлекаются метаданные и **реальные субтитры / речь** из видео через `youtube-transcript-api` для понимания сути без просмотра.
  * 📄 **Документы и файлы:** анализ файлов кода (`.py`, `.js`, `.json`), заметок (`.txt`, `.md`) и документов.
* ИИ анализирует материал по двум главным критериям:
  1. **Что это такое** (краткая суть без воды).
  2. **Зачем это надо команде** (практическая польза и варианты применения).
* Автоматически определяет категорию и переносит карточку в соответствующую тематическую ветку с кликабельной ссылкой на оригинал.

### 2. 📁 Автосоздание веток с закреплением README
* Если подходящей ветки ещё нет в группе, бот создаёт её автоматически через Telegram API.
* При создании новой ветки ИИ сразу генерирует вводный регламент топика и **автоматически закрепляет его первым сообщением** (`pin`).

### 3. 📝 Интерактивная генерация ТЗ в 1 клик
* Под каждой карточкой материала есть инлайн-кнопка **`[📝 Сгенерировать задачу / ТЗ]`**.
* При клике любым разработчиком ИИ прямо в ветке формирует готовый черновик задачи:
  * 🎯 **Цель задачи**
  * 📋 **Критерии приёмки (DoD)**
  * 🛠 **План реализации**

### 4. ⚙️ Админ-панель прямо в Telegram (`/admin`)
* Доступна только администраторам группы (указанным в `.env`).
* **Смена системного промпта на лету:** можно изменять правила и инструкции для ИИ прямо из чата.
* **Смена модели:** переключение между `gpt-4o-mini`, `deepseek/deepseek-chat` и другими моделями в реальном времени.
* **Статистика:** количество разобранных материалов и топ веток.

### 5. 📢 Умный дайджест материалов (`/digest`)
* Генерация сводки топ-находок команды за последнее время без лишнего шума и пустых категорий.
* Публикация в специальную ветку «📢 Дайджесты» в чистом Telegram HTML-формате.

### 6. 🔍 Поиск по базе знаний (`/ask` или тег @бота)
* Вопрос боту: `/ask какие библиотеки по парсингу на python мы скидывали?`
* Бот ищет по локальной базе SQLite и даёт структурированный ответ со ссылками.

### 7. 📚 Экспорт в Obsidian / Notion (`/export`)
* Выгрузка полной базы знаний в один структурированный файл `telegram_knowledge_base.md`.
* Полная совместимость с **Obsidian**, **Notion Database** и **GitHub Wiki**.

### 8. 🛡 Защита от дублей
* Автоматическая проверка повторных ссылок. Если материал уже был в группе, бот предупредит и укажет ветку, где он обсуждался.

## 🛠 Технологический стек
* **Язык:** Python 3.10+
* **Фреймворк:** [aiogram 3.x](https://github.com/aiogram/aiogram) (асинхронная работа с Telegram Bot API)
* **LLM Интеграция:** Асинхронный OpenAI Client (полная совместимость с OpenAI, OpenRouter, DeepSeek, Groq, Ollama)
* **База данных:** SQLite (хранение настроек, маппинга топиков и истории материалов)
* **Парсинг:** `httpx`, `BeautifulSoup4`, `youtube-transcript-api`

## 🚀 Быстрый старт и установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/username/telegram-forum-assistant.git
cd telegram-forum-assistant
```

### 2. Создание виртуального окружения
```bash
# Linux / macOS
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка файла переменных окружения (`.env`)
Скопируйте пример конфигурации:
```bash
cp .env.example .env
```
Откройте `.env` и укажите ваши параметры:
```env
# Токен бота от @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ

# Telegram ID администраторов через запятую
ADMIN_IDS=123456789,987654321

# Базовый URL API (OpenAI / OpenRouter / DeepSeek / Ollama)
OPENAI_BASE_URL=https://api.openai.com/v1

# API ключ провайдера
OPENAI_API_KEY=sk-...

# Модель ИИ
OPENAI_MODEL=gpt-4o-mini

# Температура генерации (рекомендуется 0.2)
OPENAI_TEMPERATURE=0.2

# Максимальное количество токенов в ответе
OPENAI_MAX_TOKENS=2000

# Имя ветки для входящих материалов
DEFAULT_INBOX_TOPIC_NAME=📥 Входящие
```

## 👥 Настройка группы в Telegram

1. Создайте супергруппу в Telegram.
2. В настройках группы **включите «Темы» (Topics / Форум)**.
3. Добавьте вашего бота в группу и назначьте его **Администратором**.
4. Обязательно выдайте боту права:
   - ✅ **Управление темами (Manage Topics)**
   - ✅ **Закрепление сообщений (Pin Messages)**
   - ✅ **Отправка сообщений**
5. В любом топике отправьте команду:
   ```text
   /setup
   ```
   Бот автоматически создаст и настроит ветку **«📥 Входящие»**.

## 💻 Запуск бота

### Обычный запуск:
```bash
python bot.py
```

### Запуск в фоне на сервере (systemd):
Создайте файл `/etc/systemd/system/tg-assistant.service`:
```ini
[Unit]
Description=Telegram Forum AI Assistant
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/telegram-forum-assistant
ExecStart=/opt/telegram-forum-assistant/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
Активируйте сервис:
```bash
sudo systemctl daemon-reload
sudo systemctl enable tg-assistant
sudo systemctl start tg-assistant
```

## 📋 Справочник команд

| Команда | Описание | Доступ |
| :--- | :--- | :--- |
| `/setup` | Создание и привязка ветки «📥 Входящие» | Админы группы |
| `/admin` | Интерактивная админ-панель (промпт, модель, статистика) | Админы из `ADMIN_IDS` |
| `/digest` | Сформировать дайджест последних материалов | Все участники |
| `/ask <вопрос>` | Поиск по сохранённой базе знаний группы | Все участники |
| `@bot <вопрос>` | Обращение к боту с вопросом по базе | Все участники |
| `/export` | Выгрузка базы знаний в формате `.md` (Obsidian/Notion) | Все участники |
